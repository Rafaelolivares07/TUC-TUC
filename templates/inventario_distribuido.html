🔄 Inventario Físico Distribuido

Esta metodología realiza inventarios físicos distribuidos en el tiempo, de uno en uno, mientras el usuario trabaja normalmente en otras tareas. Al final del ciclo, se alcanza el 100% del inventario físico sin necesidad de un cierre estresante.

¿Cómo funciona? El sistema detecta una pausa en la navegación del usuario y le presenta un ítem para contar. El operario ingresa la cantidad física sin ver el stock del sistema, y el ajuste se realiza automáticamente. Los conteos toman máximo 3 minutos por ítem.

Los ajustes de inventario solo son visibles para el parametrizador, nunca para el operario que realiza el conteo.

⚙️ Configuración

Duración total del ciclo de conteo en días. Todos los ítems deben estar contados al finalizar este período.

Si el usuario cancela o salta un conteo, el sistema esperará este tiempo antes de volver a pedirle.

Hora a partir de la cual se pueden mostrar conteos. Fuera de este horario no se interrumpe al usuario.

Hora límite para mostrar conteos. Después de esta hora el sistema deja de pedir hasta el día siguiente.

Tiempo mínimo de inactividad (en segundos) en una pantalla habilitada antes de mostrar el modal de conteo.

Define qué ítems aparecen primero. "Valor × Rotación" prioriza productos de alto valor que se mueven rápido.

Selecciona en qué pantallas del sistema se detectará la pausa para mostrar el conteo. Solo se activa en los módulos marcados.

Al completar el 100% de conteos, inicia un nuevo ciclo automáticamente sin configuración adicional.
